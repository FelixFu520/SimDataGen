# 新数采四目相机与雷达外参速览

适用于本目录四段实景数据，标定版本 `v1_261020`。完整精度以 [`calibration/v1_261020/rig_calibration.yaml`](calibration/v1_261020/rig_calibration.yaml) 为准；下表平移仅供辨认，**计算时不要使用表内舍入值**。

## 方向怎么读

`T_A_from_B` 表示把 **B 坐标中的点变到 A 坐标**：`p_A = T_A_from_B × [x, y, z, 1]ᵀ`。每个 4×4 矩阵左上 3×3 是旋转 `R`，最右列前三项是平移 `t`，单位米；`t` 是 **B 原点在 A 坐标中的位置**，不一定是相机实际安装位置。相机采用光学坐标：x 向右、y 向下、z 向前。第 3 目是整套相机的坐标基准。

## 相机之间

| YAML 字段 | 点的变换方向 | 平移 `t`（米，约值） |
|---|---|---|
| `cam0.T_camera_from_cam3` | 第 3 目 → 第 0 目 | `[-0.154113, +0.000215, -0.152361]` |
| `cam1.T_camera_from_cam3` | 第 3 目 → 第 1 目 | `[+0.001550, +0.002954, -0.306824]` |
| `cam2.T_camera_from_cam3` | 第 3 目 → 第 2 目 | `[+0.153695, -0.000210, -0.152042]` |
| `cam3.T_camera_from_cam3` | 第 3 目 → 第 3 目 | 单位矩阵，零平移 |

以第 3 目的朝向看，第 0 目大致朝右、第 2 目朝左、第 1 目朝后。**相机中心位置不能直接拿上表的 `t` 当坐标**；要在第 3 目坐标中求当前相机中心，应使用 `−Rᵀt`。任意两目之间的变换可通过第 3 目组合得到。

## 雷达与相机之间

以下矩阵都把**已做光心补偿的雷达点**变到对应相机；用于雷达点投影到图像。

| YAML 字段 | 点的变换方向 | 平移 `t`（米，约值） |
|---|---|---|
| `cam0.T_camera_from_corrected_lidar` | 雷达 → 第 0 目 | `[-0.062619, -0.138459, -0.155752]` |
| `cam1.T_camera_from_corrected_lidar` | 雷达 → 第 1 目 | `[+0.001932, -0.137436, -0.217921]` |
| `cam2.T_camera_from_corrected_lidar` | 雷达 → 第 2 目 | `[+0.062779, -0.139305, -0.151684]` |
| `cam3.T_camera_from_corrected_lidar` | 雷达 → 第 3 目 | `[-0.000319, -0.139035, -0.091007]` |

顶层 `T_cam3_from_corrected_lidar` 与表中最后一项相同。每目的 `T_corrected_lidar_from_camera` 是对应矩阵的**逆**，方向为相机 → 雷达，并非另一套标定结果。

**使用前提：**原始 JT128 雷达 XYZ 和从 0 开始编号的 `ring`，须按标定包内 `lidar_optical_correction.py:corrected(a)` 做一次光心补偿；上游若已做相同补偿，不要重复。不要额外叠加旧预旋转或逐线距离偏置。本标定与数据绑定，不代表曝光同步或独立精度验收已完成。
